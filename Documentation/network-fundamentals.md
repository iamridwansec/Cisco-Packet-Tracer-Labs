## Topic Overview

**Topic Name:** Network Fundamentals

Network Fundamentals is the study of how computers, servers, mobile devices, printers, switches, routers, and other network-enabled devices communicate with one another. It provides the knowledge required to understand how information is transmitted, received, secured, and managed across local and global networks.

This topic serves as the foundation for Cisco networking, cybersecurity, cloud computing, systems administration, and modern IT infrastructure.

## Definition

A computer network is a collection of two or more devices connected together for the purpose of sharing information, resources, and services.

These devices communicate using standardized communication protocols such as TCP/IP.

A network may consist of:

- Computers
- Servers
- Smartphones
- Tablets
- Printers
- Routers
- Switches
- Firewalls
- Wireless Access Points
- IoT Devices

---

## Purpose

Computer networks exist to allow devices to communicate efficiently.

Without networking:

- Computers cannot share files.
- Internet access would not exist.
- Email could not function.
- Cloud services would not exist.
- Online banking would be impossible.
- Video conferencing would not work.
- Businesses could not share centralized resources.

Networking allows people and organizations to communicate quickly, securely, and efficiently regardless of physical location.

## History

Computer networking has evolved over several decades.

Major milestones include:

- 1969 – ARPANET becomes the first packet-switched network.
- 1974 – TCP protocol is introduced.
- 1983 – TCP/IP becomes the standard networking protocol.
- 1984 – Domain Name System (DNS) is created.
- 1990 – The World Wide Web begins to emerge.
- Today – Modern networking supports cloud computing, IoT, artificial intelligence, and billions of connected devices worldwide.

## Key Terminology

| Term | Meaning |
|------|---------|
| Network | A group of connected devices that communicate with one another. |
| Host | Any device connected to a network. |
| Node | Any device capable of sending or receiving data. |
| Client | A device requesting services. |
| Server | A device providing services. |
| Packet | A unit of transmitted data. |
| Protocol | A set of communication rules. |
| Bandwidth | Maximum data transfer capacity. |
| Latency | Delay experienced during communication. |
| Throughput | Actual amount of transmitted data. |
