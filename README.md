# Cisco Packet Tracer Labs

A collection of Cisco Packet Tracer labs documenting my hands-on networking journey as I work toward a career in cybersecurity.

This repository contains practical networking labs covering core CCNA concepts, router and switch configuration, network troubleshooting, and routing protocols.

---

## Objectives

- Strengthen networking fundamentals
- Practice Cisco IOS configuration
- Build a documented networking portfolio
- Prepare for cybersecurity and ethical hacking roles

---

## Skills Covered

- Network Fundamentals
- IPv4 Addressing
- Subnetting
- VLAN Configuration
- Trunking
- Inter-VLAN Routing
- Static Routing
- RIP
- OSPF
- Network Troubleshooting
- Router Configuration
- Switch Configuration
